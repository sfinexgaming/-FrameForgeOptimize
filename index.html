02
WINDOWS BASELINE

Clean up Windows for gaming

Do the safe fundamentals before advanced tweaks.

  1. Set monitor refresh rate: Settings → System → Display → Advanced display.
  2. Enable Game Mode: Settings → Gaming → Game Mode.
  3. Check startup apps: Task Manager → Startup apps → disable apps you don't need.
  4. Graphics preference: Settings → System → Display → Graphics → select the game and choose the appropriate GPU option.
  5. Check temperatures: make sure CPU/GPU temperatures and clocks remain normal under load.
  6. Check RAM: confirm the expected capacity and supported memory configuration.

03
ADVANCED · OPTIONAL

AtlasOS

AtlasOS is an advanced Windows modification. It can reduce background activity, but it is not required for gaming and there is no guaranteed FPS gain.

Before installing: back up your files. Atlas' current documentation requires a full Windows reinstall for its supported installation path.
Read the AtlasOS guide →Official Atlas docs
04
LATENCY

Reduce input delay

Work through these in order instead of applying random “latency tweaks”.

  1. Use the monitor's maximum supported refresh rate.
  2. Check V-Sync: test with your game's recommended low-latency configuration.
  3. Use a stable FPS cap: compare uncapped versus a cap your PC can sustain.
  4. Mouse polling: test your mouse's supported polling rates; higher is not automatically better on every system.
  5. Use NVIDIA Reflex or AMD Anti-Lag 2 when supported by the game and follow the game's documentation.
05
NETWORK

Optimize ping and connection stability

Windows tweaks cannot magically change the physical route to a game server. Focus on the things you can measure.

  1. Use Ethernet when possible.
  2. Stop heavy uploads/downloads while gaming.
  3. Test at the same time of day when comparing connections.
  4. Check the game's server/region selection and choose the closest appropriate region.
  5. Measure packet loss and jitter, not just the headline ping number.
06
GAME SETTINGS

Configure the game for your hardware

Start with the game's own settings. Competitive settings are not identical for every PC.

GPU-limited?Lower resolution or GPU-heavy settings first.
CPU-limited?Lower CPU-heavy settings and background load.
Stuttering?Investigate frametime, shaders, drivers and thermals.
Competitive?Prioritize consistent frametime and a stable FPS target.
07
VERIFY

Benchmark before and after

This is the step most “FPS optimization” websites skip. Don't trust a tweak because it sounds good.

Average FPS1% lowsFrametimeCPU/GPU usageTemperaturesPing / packet loss

Change one variable at a time. If performance gets worse, revert the change.
